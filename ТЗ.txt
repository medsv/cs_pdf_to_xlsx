process_pdfs.py - консольное Python приложение для обработки pdf файлов и формирования результата их обработки в файл xlsx.
Создай файл app.py в котором создаётся приложение Streamlit (вместо main в process_pdfs.py), позволяющее принимать на вход (upload) несколько pdf файлов с любым названием и позволяющее скачивать итоговый xlsx-файл.
Используй process_pdfs.py в качестве библиотеки, загружаемой в app.py.
